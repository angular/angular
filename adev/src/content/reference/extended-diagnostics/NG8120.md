# An attribute resolver shadows a directive output of the same name.

This diagnostic detects an attribute resolver binding on an element, such as `(class)`, `(style)`, or `(attr.role)`, where a directive declares an output of the same name.

<!-- prettier-ignore -->
```angular-ts
import {Component, Directive, output} from '@angular/core';

@Directive({selector: '[highlight]'})
class Highlight {
  readonly changed = output<string>({alias: 'class'});
}

@Component({
  imports: [Highlight],
  template: `<div highlight class="px-2" (class)="(cn) => cn('shadow-lg')"></div>`,
})
class MyComponent {}
```

## What's wrong with that?

A `(class)` binding on an element resolves the element's classes from all sources, and so does `(attr.class)`.
In the same way, `(style)` and `(attr.style)` resolve the element's styles, and `(attr.role)` resolves its `role` attribute.
The binding resolves the attribute even when a directive on the element declares an output of the same name, so the output's emissions never reach the binding.

## What should I do instead?

Rename the directive's output, and listen to it under its new name.

```angular-ts
import {Component, Directive, output} from '@angular/core';

@Directive({selector: '[highlight]'})
class Highlight {
  readonly changed = output<string>({alias: 'highlightChange'});
}

@Component({
  imports: [Highlight],
  template: `
    <div
      highlight
      class="px-2"
      (class)="(cn) => cn('shadow-lg')"
      (highlightChange)="onHighlightChange($event)"
    ></div>
  `,
})
class MyComponent {
  onHighlightChange(value: string) {}
}
```

## Configuration requirements

[`strictTemplates`](tools/cli/template-typecheck#strict-mode) must be enabled for any extended diagnostic to emit.
`outputShadowedByAttributeResolver` has no additional requirements beyond `strictTemplates`.

## What if I can't avoid this?

This diagnostic can be disabled by editing the project's `tsconfig.json` file:

```json
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "outputShadowedByAttributeResolver": "suppress"
      }
    }
  }
}
```

See [extended diagnostic configuration](extended-diagnostics#configuration) for more info.
