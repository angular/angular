# Unsupported Binding on a Form Field

A template binds, or sets as a static attribute, a property that Signal Forms already controls on an element using the `[formField]` directive.
The field state is the single source of truth for values like `min`, `max`, `required`, `disabled` and `readonly`, so a second value in the template could only conflict with it.

The error message names the binding. It reads either "Binding to '[min]' is not allowed..." or "Setting the 'required' attribute is not allowed...".

```angular-ts
import {Component, signal} from '@angular/core';
import {form, FormField} from '@angular/forms/signals';

@Component({
  selector: 'app-root',
  imports: [FormField],
  template: `
    <!-- NG8022: [min] and [max] are not allowed with [formField]. -->
    <input type="number" [formField]="f.age" [min]="18" [max]="99" />

    <!-- NG8022: the required attribute is not allowed with [formField]. -->
    <input type="text" [formField]="f.name" required />
  `,
})
export class App {
  f = form(signal({age: 20, name: ''}));
}
```

The same applies to a [custom form control](guide/forms/signals/custom-controls) when the template binds an input that the field manages, like `[max]` on a control that declares a `max` input.

The properties that can't be used with `[formField]` are `value`, `checked`, `errors`, `dirty`, `disabled`, `disabledReasons`, `hidden`, `invalid`, `name`, `pending`, `readonly`, `touched`, `max`, `maxLength`, `min`, `minLength`, `pattern` and `required`. On native elements the lowercase `maxlength` and `minlength` attributes are not allowed either.

There are two exceptions on native elements. `min` and `max` are allowed on `<input>` elements of type `date`, `time`, `month`, `week` and `datetime-local`, and when the `type` is bound dynamically. `value` is allowed on `<input type="radio">`.

## Debugging the error

Remove the binding from the template and declare the rule in the schema function of `form()` instead. The field state then applies the rules to the element or control:

```angular-ts
import {Component, signal} from '@angular/core';
import {disabled, form, FormField, max, maxLength, min, required} from '@angular/forms/signals';

@Component({
  selector: 'app-root',
  imports: [FormField],
  template: `
    <input type="number" [formField]="f.age" />
    <input type="text" [formField]="f.name" />
  `,
})
export class App {
  f = form(signal({age: 20, name: ''}), (p) => {
    min(p.age, 18);
    max(p.age, 99);
    required(p.name);
    maxLength(p.name, 20);
    disabled(p.name, {when: ({valueOf}) => valueOf(p.age) < 18});
  });
}
```

Rules like `disabled()`, `readonly()` and `hidden()` take an optional `when` condition, so a rule can depend on other fields. See [form logic](guide/forms/signals/form-logic) for the full list.
