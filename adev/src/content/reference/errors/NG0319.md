# Binding on ng-container or ng-template has no effect

A template puts a binding on `<ng-container>` or `<ng-template>` that has no effect, because neither element renders a DOM element.

In development mode, Angular reports the following bindings when it creates a template:

- Class and style bindings that no directive input takes over. On `<ng-container>`, this covers `[class]`, `[style]`, and bindings such as `[class.active]` or `[style.width]`. On `<ng-template>`, it covers only `[class]` and `[style]`: Angular treats `[class.active]` and `[style.width]` on `<ng-template>` as property bindings, and reports them as unknown properties (NG0303).
- Event bindings, such as `(click)`, that no directive output claims and that have no global target such as `window:` or `document:`.

```angular-ts
import {Component, signal} from '@angular/core';

@Component({
  selector: 'app-item',
  // NG0319: neither binding has an effect, because <ng-container> doesn't render an element.
  template: `
    <ng-container [class.active]="active()" (click)="select()">
      <span>{{ label }}</span>
    </ng-container>
  `,
})
export class Item {
  label = 'Item';
  active = signal(false);

  select() {
    this.active.set(true);
  }
}
```

Angular logs this error with `console.error`. Host bindings of directives aren't reported, because a directive can also be applied to elements where those bindings work.

## Debugging the error

Use the binding and the component name in the error message to find the template. Then pick the fix that matches what the binding was meant to do:

- **Style or listen to the content**: move the binding to an element inside the `<ng-container>` or `<ng-template>`, or replace it with an element.
- **Set a directive input or listen to a directive output**: add the directive to the component's `imports`.
- **Nothing reads the binding**: remove it.

With [`strictTemplates`](tools/cli/template-typecheck#strict-mode), the compiler reports these bindings at build time as [NG8031](errors/NG8031), along with other bindings and attributes that `<ng-container>`, `<ng-template>`, and `<ng-content>` ignore.
